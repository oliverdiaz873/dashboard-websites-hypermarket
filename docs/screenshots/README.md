# Screenshots — Dashboard Hipermercado Superior

Capturas para el portfolio. La carpeta aloja los `.png` reales una vez capturados;
este `README` mantiene el registro de vistas pendientes.

## Screenshots

| Vista                                                       | Archivo              | Estado            |
| ----------------------------------------------------------- | -------------------- | ----------------- |

| Estadísticas                                                | `stats.png`          | Pendiente captura |

## Cómo capturar (checklist)

1. Levantar backend (`npm run dev`) y dashboard (`npm start`).
2. Iniciar sesión con un usuario `admin` (seed del backend).
3. Capturar en tamaño de ventana 1440×900 (desktop) y, si aplica, móvil.
4. Guardar como PNG en esta carpeta con el nombre indicado.
5. Actualizar la tabla de estado a `Lista` para cada archivo añadido.
